- Python 3.8 真实环境能够导入 minbt 与两个通用存储 Feed，并通过本轮回归。
- 1,000 资金、price=29 的 100% 目标成功；确实超过可用现金的订单仍拒绝。
- 极大有限数量或派生金额溢出时，无持仓、现金、订单、退出或盈亏部分提交。
- 资金 200、杠杆 10，A/B 各 10@100，完整行情 A=85/B=112 时，A 平仓、部分减仓与止损成功；权益与净盈亏恒等式成立。
- 资金 1,000、A/B 各 50@100，行情 A=89/B=94 时，两种建仓顺序普通全平均得到现金 150、零持仓。

- 仅 News 触发 alpha 退出时，beta 和 Broker 的 A 报价时间仍为旧行情时间；成交时间为 News 批次。
- 撤单时间有效；独立分仓平仓保留旧报价时间；1000 毫秒解析为 epoch 后 1 秒。
- 非法分仓名称不改变资金和分仓集合；均线首行 close 在真实 close_time 可见。
- 全量测试、代码 review、静态检查通过，结果文档列出实际执行与限制。
