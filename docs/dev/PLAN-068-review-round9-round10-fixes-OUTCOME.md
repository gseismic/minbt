## Review 修正

1. 仅允许单笔减仓欠款仍不能消除普通全平的手续费顺序差异。全平现为整组扣费，避免某笔费用
   提前触发免手续费强平。PLAN-067 的对应回归改为两种顺序均 filled/filled、总权益 159、
   净盈亏 -1111；单笔交易和市场批次的即时风险检查继续保留。
2. 现金欠款不能成为开仓或反手资金；市场的交易时间、整手、禁空、T+1 仍在成交前检查。
   亏损腿减仓后，盈利腿可偿还欠款；其他分仓归还非负资金也可分次偿还 main。
3. 显式报价影响同标的所有分仓，数值预检不能只检查下单分仓。跨分仓估值溢出在报价和时钟
   写入前拒绝；归还资金或归档统计溢出也必须先拒绝，不能先成交、撤单或删除分仓。
4. 候选数值还包括累计数量、成本、保证金、各标的及整个账户的记账统计。真实现金、持仓和
   成交明细使用同一份已验证候选金额，Position 活对象身份保持。
5. Python 3.8 可安装的 Matplotlib 使用旧无界面警告文本。测试仅过滤新旧两种已知 GUI 提示，
   保留对其他 stderr 的严格检查，未更改产品绘图行为。
6. 完成核验发现当前权益乘比例有限、上涨后的权益乘比例溢出的请求会先更新报价。
   比例目标现用候选行情及风险后的权益提前检查乘除；复现后报价、时钟、订单和退出保护均保持。
