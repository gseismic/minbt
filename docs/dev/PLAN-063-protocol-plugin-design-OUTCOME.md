## 收敛结果

1. 直接复用现有 Exchange、Strategy、Broker 和 RunResult，不重写主循环。
2. 数据由用户准备、解释和读取；核心不获取数据、识别市场、推断时点或选择数据 SDK。
3. 自定义 Feed/Broker 直接注入，可独立组合，不要求市场包或注册名称。
4. 原数据源与交易实现可移至 plugins，原入口重导出，避免复制方法和状态。
5. 协议优先集中已有定义，只补实际回放依赖，结果协议沿用已有查询。
6. 薄 run 在需要时才增加，以用户 Feed/Broker 工厂装配；其他引擎有真实需求时再适配。
7. 撤回当前必需的注册表、组合绑定、Router、命令后端、阶段框架、完整记录管线和多表保存安排。
8. 不新增额外金融口径和来源推断，用户模型的解释与计算属于其 Broker。
