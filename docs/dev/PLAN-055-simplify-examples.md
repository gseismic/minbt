# PLAN-055：精简示例中的冗余检查

## 目标

让当前 `examples/` 下每个示例都能独立运行，不依赖其他示例文件；示例聚焦于 minbt API 和策略逻辑。

## 范围

- 检查当前维护的 `examples/*.py` 全部 Python 示例及 README、使用 skill、设计文档和示例测试。
- 删除 `example_utils.py`、`plot_utils.py`，让每个示例不依赖其他示例文件。
- 移除绘图代码及仅用于绘图的依赖，让示例集中展示策略与数据 Feed。
- 使用标准库和 `list[dict]` 构造内存示例数据，删除仅用于数据帧转换的第三方依赖。
- 高级示例直接调用 Broker 接口，不通过共享调仓辅助模块。
- 删除重复的外部资源预检和历史查询列表包装。
- 保留策略行为、盈亏 sanity check、Feed 专项主题和示例所需的实际数据配置。
- 不修改 `docs/versions/v0/examples/` 历史快照。

## 实施步骤

1. 逐个审阅当前示例，确认冗余检查及其调用方。
2. 将共享工具职责移除或收敛到各自示例中，保持每个示例自包含且精简。
3. 更新 README、使用 skill、设计文档与示例测试，移除共享工具、绘图和环境变量说明。
4. 复查差异，搜索示例中遗留的跨示例导入，并运行适当检查。
5. 记录结果与外部数据源验证边界。

## 验收标准

- 当前示例不再导入其他 `examples/` 文件，`example_utils.py` 和 `plot_utils.py` 不存在。
- 内存数据示例只使用标准库构造数据。
- 示例不再对公开返回列表的历史数据做兼容性探测。
- Feed 专项示例仍明确展示对应的数据源。
