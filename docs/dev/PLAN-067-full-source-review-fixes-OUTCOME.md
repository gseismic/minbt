## 复查补充

1. 独立 Position 反手原本会先全平再检查新开参数，因此把全部参数检查提前，并补充仓位不变验证。
2. 成交后即时风险检查使关闭分仓的一笔手续费可能先清掉其他仓位。修正全平预检与执行按最新仓位计算，已强平标的返回 skipped；实际场景验证关闭成功、取消/归档流程正常、全账户权益 160、净盈亏 -1110。
3. 退出规则工厂只增加校验，不改变原默认规则名称；复查发现的名称格式变化已修正。
4. 同步 README、最新协议与随包 Skill；新增不变式设计并在旧数据设计顶部明确当前时间契约。通用 storage 的 symbols 仍是筛选条件、可部分命中；Binance reader 检查每个请求标的，现已明确说明。
5. 报价时间与风险结算时间分开传递；沿用旧报价的较晚成交手续费或其他标的行情触发强平/穿仓时，风险明细也按实际结算批次记录。关闭分仓回归额外断言了这条时间边界。
6. 完成核验发现独立 Portfolio 的零数量请求仍会先推进报价和风险，最小复现返回 False 却把 1 单位多仓强平、权益 100 变为 5。现将数量检查移到风险推进前；保留返回 False，并通过两条价格路径断言活持仓、报价时间、现金、权益和盈亏记录全部不变。
