## 验收标准

- 普通交易满足 `net_pnl = realized_pnl + unrealized_pnl - fees`；穿仓时额外包含显式的结算调整。
- 从 Broker 创建至今的全账户净盈亏，始终与 `get_total_equity() - initial_cash` 在浮点误差内一致。
- 覆盖多空、加仓均价、部分平仓、双向反手、手续费、杠杆、多标的、多 Portfolio、分仓关闭和名称复用。
- 挂单预检、批量关闭预检、拒绝、撤单和跳过不重复记账；预检中的风险结算不修改真实统计。
- 强平和穿仓统计符合当前实际现金结算，历史不因清空持仓或关闭分仓丢失。
- 查询不创建空仓，返回不可变结果和新的明细列表；现有订单、策略协议与权益历史接口兼容。
- 示例通过公开盈亏接口展示结果，保留内联绘图，无手算公式和自定义正确性断言。
- 全量测试、相关示例、ruff、Python 3.8 语法兼容检查与 `git diff --check` 通过。
