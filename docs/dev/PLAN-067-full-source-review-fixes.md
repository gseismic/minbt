## 验收标准

- 两种持仓顺序全仓强平均得到现金/权益 50、净盈亏 -950；失败单仓结算不破坏账本。
- `close_position` 与目标归零在风险清仓后保持零敞口；目标价值/比例使用风险推进后的状态。
- 限价 95 在市价 80 成交后成本仍为 95、估值为 80、权益 985、净盈亏 -15；当前批次结果快照与风险一致。
- 旧报价无法绕过当前休市与 T+1；显式旧报价时间也不能倒退运行中的交易时钟。
- 非有限数值、错误类型或非法范围不改变账户价格、资金、持仓、退出保护和盈亏记录。
- 完整小时 Kline 不在开盘时暴露最终 close/high/low/volume；三个 Binance 读取器语义一致。
- 策略修改回调容器不会影响其他策略；毫秒时间键不碰撞。
- 加仓和任意当前订单句柄修改退出配置均保留未修改的标准条件、函数规则和 state；新生命周期不继承旧条件。
- 小写/空白 symbol 使用同一持仓与市场约束；目标仓位按行情推进正确计盈亏。
- 常用目标仓位策略每批不访问历史订单，缓存拒绝首段缺失，连接正常/异常路径都关闭。
- 针对性与全量测试、Ruff、差异检查通过，原有示例修改保持原样。
