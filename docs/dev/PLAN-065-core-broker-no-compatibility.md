## 边界修正

可替换性由协议和工厂表达。默认 Broker、Portfolio、Position、Order、Pnl、撮合、退出和通用 Market
属于内置回测能力，唯一实现放回 `minbt.broker`。插件承载数据格式/来源读取及今后的特殊市场扩展；
不为目录形式把基础回测功能全部搬出核心。

删除本轮重构的模块别名、旧数据读取文件和跨目录兼容导出。更新使用处直接导入插件或协议；
保留根包常用对象导出与正常核心模块 API，不以保留旧读取路径为约束。Python 支持版本和
缺少可选存储依赖时的运行能力不属于本轮历史 API 转发清理，不改变金融算法或配置运行行为。

## 验收

- 默认 Broker 的代码直接位于 `minbt/broker`，plugins/simulation 完全移除，无 sys.modules 别名。
- 默认自备数据回测无需加载任何 minbt.plugins 模块；数据读取仅从插件入口导入。
- 自定义 Feed/Broker、结果快照、原交易数值、运行控制和资源释放继续正确。

- wheel/sdist 与仓库外安装证明核心/插件分工正确，新配置入口照常运行。
- 不新增依赖、数据服务、注册框架或回放循环；当前设计停止承诺兼容转发。
