## 验收证据

复核补充：自定义 Broker 只支持默认分仓时不得强制调用具名查询；可选数据接口声明未实现时，结果中的相关查询明确报未实现，真正的查询故障继续传播。补充退出保留 pending 订单及后续成交不污染快照的验证。

- 普通回测返回 `completed`；暂停时权益随行情变化，挂单、退出条件和风险规则仍生效，策略仅收到执行状态允许的行情。
- `exit` 返回 `exited/control_exit`，最后曲线、订单、持仓与实际最后一批一致；零进度退出也有明确元信息。
- `meta` 包含请求和实际时间、步数、最终控制状态及去重的控制变化记录，返回容器和原运行对象修改不影响旧结果。
- 默认、预加载和渐进模式对窗口和控制有相同语义；窗口外数据不推进行情账户。
- 同一 Exchange 无法重跑，内置 Strategy/Broker 无法跨运行复用；同次共享 Broker 每批只推进一次。初始化、读取、控制、行情回调、采样、结果构造、结束通知和关闭失败均不返回伪完成结果。
- 测试与示例实际运行通过；当前使用文档与代码一致，未来 live 的待实现能力明确。
