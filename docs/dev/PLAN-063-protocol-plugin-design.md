## 范围与依据

用户要求内核小、扩展能力不受限制，保留现有使用接口，集中协议，输出支持绘图。
本次只做设计与接口评审，不实施代码迁移。

最新约束：所有数据由用户准备，不新增市场数据服务依赖；自定义 Feed/Broker 直接组合。
两层扩展只保留接口边界，不为尚未使用的能力建设注册表、市场包工厂、Router、交易后端或记录框架。

本轮先前的较大扩展方案以当前 [总设计](../design/kernel-20261012-protocol-plugins.md) 和
[最小协议目录](../design/protocols/README.md) 为准。运行代码、依赖和版本不改变，不提交或推送。
