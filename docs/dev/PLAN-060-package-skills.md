## 目标和范围

把用户使用指南迁移到 `minbt/skills/minbt-usage/`，随 minbt 的 wheel 和 sdist 发布。增加当前环境的版本与资源路径定位命令，整理安装后独立可用的参考资料与最小脚本，并提供项目级发现说明和仓库相对链接。

沿用既有 setuptools 和 pytest；构建验收使用 PyPA build，安装回归使用 pip，两者加入开发依赖。构建后端在隔离构建环境中准备，测试安装到临时目录并复用测试环境已有的运行依赖。不修改交易、数据回放和结果计算接口，不改变项目版本，不维护 skill 内容副本。通用库设计 skill 继续留在开发目录。

## 完成标准

- 包内用户 skill 是唯一内容来源，所有必要引用文件进入实际安装目录。
- `python -m minbt.skills` 输出版本与目录，`--path` 输出可直接读取的绝对目录。
- 普通安装与 editable 安装均可定位资源；缺少资源时明确报错。
- 干净构建的发行物资源内容与源码一致，安装后可在仓库外执行最小回测并得到 1020。
- skill 校验、打包回归测试、全量测试、Ruff 与 `git diff --check` 通过。
- 保存结果文件；提交与推送按用户另行指令处理。

## 自查与风险

- 定位必须使用消费项目的 Python；不同虚拟环境可能安装不同版本，README 说明环境绑定。
- 不通过安装钩子自动修改全局 skills，不覆盖消费项目已有链接。
- 开发设计与发布使用说明分开维护，避免把尚未实现的接口作为可调用能力发布。
- 构建测试使用临时源码副本，安装和运行使用临时目录，不依赖仓库当前工作目录或历史构建缓存。
- 回滚可逆向迁移 skill、移除本次定位模块及配置、文档、链接和测试；不影响其他功能。
