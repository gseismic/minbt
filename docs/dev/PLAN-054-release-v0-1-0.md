# PLAN-054：发布 v0.1.0

## 目标

把最近一轮已提交的逻辑修复整理为 `v0.1.0` 发布：更新包版本、用户 README 和 minbt 使用 Skill，提交发布文件并创建对应 Git tag。

## 范围

- 将 `pyproject.toml` 版本从 `0.0.4` 更新为 `0.1.0`，Git tag 命名为 `v0.1.0`。
- 在 README 记录本次版本变更，并补充受影响的公开行为契约。
- 更新 `skills/minbt-usage/SKILL.md`，确保策略使用说明反映当前实现。
- 按仓库约定提交本计划和实施结果，并在提交后创建 annotated tag `v0.1.0`。
- 不修改 `examples/`，不改动已提交的运行时代码。

## 实施与验收

1. 更新版本号及 README、Skill 中的使用说明。
2. Review 文档，确认描述与当前实现和最近一轮修复一致。
3. 检查 TOML 版本值和 `git diff --check`；本任务不要求重跑测试。
4. 生成结果文档，以中文提交信息记录计划、结果及逐项变更；提交后创建并检查 `v0.1.0` tag。
