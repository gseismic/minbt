# 盈亏校验示例设计

## 背景

当前 `examples/001_core_demo_mini.py`、`examples/002_core_single_symbol_sma.py` 等示例主要绘制权益曲线，
但没有把盈亏定义、理论值和实际回测值放在一起展示。用户很难仅凭最终权益判断一笔交易是否按预期计算，
也不容易区分价格波动、做空方向和手续费的影响。

## 目标

新增一个完全离线、数据量很小、结果可以手算的示例，满足：

1. 展示多头盈利、空头盈利和手续费侵蚀三个最小场景。
2. 在终端输出毛盈亏、手续费、理论净盈亏、实际净盈亏和最终权益。
3. 绘制以零为基线的净盈亏曲线，正负区域直观可见。
4. 测试直接断言示例实际结果等于理论计算结果。

## 盈亏定义

示例不新增核心 API，直接使用 `Strategy.get_hist_equity()`：

```text
净盈亏(t) = 权益(t) - 初始资金
```

- 持仓未平时，净盈亏包含按最新价计算的未实现盈亏。
- 平仓后，最终净盈亏包含已实现盈亏并扣除开仓和平仓手续费。
- 对一个数量为 `qty`、入场价为 `entry`、出场价为 `exit` 的单次交易：

```text
毛盈亏 = qty * (exit - entry)
手续费 = (abs(qty) * entry + abs(qty) * exit) * fee_rate
理论净盈亏 = 毛盈亏 - 手续费
```

## 示例场景

| 场景 | 价格路径 | 数量 | 手续费率 | 理论净盈亏 |
| --- | --- | ---: | ---: | ---: |
| 多头盈利 | 100 → 110 → 120 | 1 | 0 | 20 |
| 空头盈利 | 100 → 95 → 90 | -1 | 0 | 10 |
| 小幅上涨但被手续费覆盖 | 100 → 100.05 | 1 | 0.001 | -0.15005 |
